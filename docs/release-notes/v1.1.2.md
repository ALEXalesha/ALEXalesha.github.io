Hub 1.1.2 - Horizon Drift 1.2.0 with neural rivals and new tracks from a code, RailRunner 2.0.1.

- Horizon Drift 1.2.0: rivals are driven by the AiRacer neural network - it sees only what a driver sees and presses the same pedals and wheel as the player; damage and nitro work for it by the player's rules. "Settings → Game → Rival AI" brings the old bot back. Drift races can have up to 3 rivals.
- Horizon Drift: "New track" in the menu builds a closed track from a code like R2M-3F9K1Z; the same code always gives the same track, so it can be shared. Tracks can be saved, records are kept per code.
- Horizon Drift: the festival, events and duels in free roam are on T (gamepad B), E is only "gear up". If T was already given to another action, the festival takes a free key.
- Horizon Drift, fixes after the review: the rival level matches the game's bot of the same difficulty (on "Easy" the network was a little faster than it should be); a track that is still being built stops when a race starts.
- RailRunner 2.0.1: five districts with time of day and weather, six characters and boards, a shop, missions, a daily challenge, a jetpack, tricks and a tutorial.
- The Horizon Drift card describes the game as it is now.

«Хаб» 1.1.2 - Horizon Drift 1.2.0 с соперниками-нейросетью и новыми трассами по коду, «Бег по рельсам» 2.0.1.

- Horizon Drift 1.2.0: соперников ведёт нейросеть AiRacer - она видит только то, что видел бы водитель, и жмёт те же педали и руль, что игрок; повреждения и нитро у неё по правилам игрока. «Настройки» → «Игра» → «ИИ соперников» возвращает прежнего бота. В дрифте теперь до 3 соперников.
- Horizon Drift: «Новая трасса» в меню строит замкнутую трассу по коду вида R2M-3F9K1Z; тот же код всегда даёт ту же трассу - им можно поделиться. Трассы сохраняются, рекорды - по коду.
- Horizon Drift: фестиваль, события и дуэли в свободной езде - на T (на геймпаде B), E - только «передача вверх». Если T уже отдана другому действию, фестиваль берёт свободную клавишу.
- Horizon Drift, исправления после проверки: уровень соперников совпадает с ботом игры той же сложности (на «Легко» нейросеть была чуть быстрее, чем нужно); трасса, которая ещё строится, останавливается, когда начинается заезд.
- «Бег по рельсам» 2.0.1: пять районов со сменой времени суток и погодой, шесть персонажей и доски, магазин, задания, испытание дня, реактивный ранец, трюки и обучение.
- Карточка Horizon Drift описывает игру такой, какая она сейчас.
